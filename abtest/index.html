A Gap Factory A/B test rebuilt from the original June 2023 assets. The offer is the same in both versions. What changes is the subject line, the preheader and the hero image.

The setup

How the test runs

Part of the audience gets each version. Opens show which subject line and preheader worked; clicks show which hero image worked. Every version is checked on a test send before the split goes out.

  1. 01BuildOne template, two versions
  2. 02SplitTest audience divided evenly between A and B
  3. 03MeasureOpens for subject and preheader, clicks for the image
  4. 04SendThe winning version goes to everyone else

Where it carries over

Any email program tests the same way: change one or two things, keep the rest identical, split the audience and let opens and clicks decide. Personalizing the subject line with a safe fallback works with any customer data.
